## How to merge

- What was read about the same behaviour or outcome becomes one point, with the link of everything read about it in `links`: the script adds each one's day. Write a pattern as one: "Jane didn't update the rollout's status, many times", not one point per day. Keep apart points that are about different things, even when they share a value.
- When what was read about the same thing disagrees, keep both as points, or say how it changed, such as "Jane shared progress rarely in July, every week from September".
- `context` points have `links` too. Merge context that says the same thing into one.
- When nothing is worth keeping, submit every part empty.

When you're in doubt whether something should be a point, leave it out, and list it in `in_doubt` with its day, or its page's title, what it says and why, so the manager can see it. Each line of `in_doubt` is written as a point is.
