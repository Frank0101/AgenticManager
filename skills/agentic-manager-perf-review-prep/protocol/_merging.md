### Merging and citing points

What the source says more than once about the same behaviour or outcome is one point, never one per mention: a behaviour seen on several occasions is written as the pattern it is, "Jane didn't update the rollout's status, many times", not one point per day. A point that rests on several occasions of the same thing, such as support for one team, says what the person did across them as a whole: the kind of contribution, how long and how often when the source shows it, such as "repeatedly, from July to November", and its effect, with a moment's details only as one or two examples. Keep apart points about different things, even when they share a value; context that says the same thing is one point. A point names only a period its source shows, such as "since August" when something says so. When the same thing is partly good and partly to improve, such as a habit that changed, make two points, one in each part, each saying when it held: weighing one against the other isn't yours to do.

Each point cites in `cites` the numbers of the {{cited}} it rests on, every one that shows it: the script adds each one's day and link, so a pattern cites every one of it. A point says only what the {{cited}} it cites show: it credits the person with their own part and doesn't extend to the others a detail that only one of them has. {{citations_more}}

| ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- | ----------------------------------------------------- |
| Sam (Jul), Alex (Aug) and Kim (Sep) each thanked Jane by name for help with the API                                          | One point, going well, citing all three | Small each time, but a pattern over months: one point |
| Jane paired with Sam on the API (Jul); reviewed Sam's design (Sep); Sam presented the API on their own, crediting Jane (Oct) | One point, citing all three             | Ongoing mentoring, not three tasks                    |
