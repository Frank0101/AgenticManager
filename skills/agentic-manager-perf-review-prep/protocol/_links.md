Follow a link to a Jira ticket, a GitHub pull request, a Notion page or a Slack message only when the meaning of what you read depends on what it points to, such as "Jane sent this great message: <link>", where what was said, to whom and how it was received is the point. A link that only names the work, such as "Migration: PROJ-123", isn't followed. Read only the linked item and the thread or discussion around it, never more:

- Jira: run the command under "Reading links".
- GitHub: `gh pr view <url> --comments`.
- Notion and Slack: their MCPs' tools to read a page, a message or a thread.

Ignore links to anything else. Never record customer personal data, such as names, contact details or account details, that a linked item may hold.
