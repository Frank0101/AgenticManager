# Read a month of a manager's notes

A manager is preparing a performance review of the person named below. These are the notes from the manager's journal over one month that mention the person, each numbered, with the day it was written, and shown inside the block it sits in, so the lines around it give its context: the lines that mention the person start with →. Write a synopsis of every note, for another agent that won't see the notes and decides, across the whole period, what in them is feedback. Leave none out, even one where the person is only a name in passing.

## Each synopsis

Say what the note says about the person:

- what they did or didn't do, what happened because of them, what someone said about them, or how they're compared with others or held up as a model;
- who it was for or helped, and what changed because of it, such as a new way of working, another team unblocked or a process improved, as far as the note says;
- the context the lines around it give, such as who the note is about when it's about someone else, or what "it" refers to;
- how it ends: a later line, nested under it or further down the same day, can settle an earlier one, such as a concern followed by "all fine", or a missing task followed by "done", so say what the note ends up saying, not its first line alone;
- what kind of note it is, when that isn't plain, such as a to-do for the manager, the status of the work, or the person named only in passing.

## Examples

| Note                                                                                                                 | Synopsis                                                                                                          |
| -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| "Jane has already done it instead - well done!", under a line saying Sam set personal objectives unprompted          | Jane had already set personal objectives without being asked, unlike Sam; the manager wrote "well done"           |
| "Jane said in Slack 'on it', but didn't move the ticket - to check", with "-> all fine, in progress" nested under it | The manager wondered whether Jane had started a ticket that hadn't moved, then found it was in progress, all fine |
| "Jane, Sam and Alex in the planning sync"                                                                            | Jane is named only among the planning sync's attendees                                                            |
| "Ask Jane about the rollout"                                                                                         | A to-do for the manager: ask Jane about the rollout                                                               |
